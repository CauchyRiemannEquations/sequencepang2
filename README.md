# 시퀀스팡2 · SEQUENCEPANG 2

등차·등비수열을 연결해 별을 모으는 모바일 퍼즐입니다. 2026년 10월 1일 0시(한국 시간)부터 100스테이지를 제공합니다. 최대 보드는 5×5입니다.

## 실행과 검증

```sh
npm run build:pwa
npm start
npm test
```

Node 20 이상을 사용합니다. `dist/`는 별도 빌드 없이 정적 호스팅할 수 있습니다. ES 모듈이므로 HTML 더블 클릭 대신 HTTP 서버로 실행합니다.

## 화면과 조작

- 제공된 시퀀스팡2 로고를 메인과 게임 화면에 사용합니다. 짙은 초록 배경, 금색 프레임, 크림색 타일, 주황색 선택 강조를 적용했습니다.
- 메인에는 시작하기, 플레이 방법, 설정, `cremationmath@gmail.com` 문의 링크가 있습니다. 문의 버튼은 플레이 방법과 같은 줄에 있으며 이메일 주소는 화면에 표시하지 않습니다. 스테이지 선택 메뉴는 없습니다.
- 모바일에서는 로고와 여백을 줄이고 게임판을 현재 화면 높이와 튜토리얼 높이에 맞춥니다. 매우 낮은 가로 화면에서는 터치 영역을 유지하며 스크롤을 허용합니다.
- 설정의 게임 초기화는 확인창을 거쳐 완료 기록, 망고 힌트와 현재 판을 지우며, 효과음 설정은 유지합니다.
- 마지막 공개 스테이지를 클리어하면 완료 화면을 표시합니다. 10월 1일 전에는 50단계까지만 표시하고, 한국 시간 10월 1일 0시부터 51–100단계가 열립니다. 메인에는 공개 후에만 “100단계 업데이트!”를 표시합니다. 기존 완료 기록은 유지하며 51단계부터 이어집니다.
- 시작하기는 마지막으로 하던 스테이지를 처음부터 시작하거나 첫 미완료 스테이지로 이동합니다. 기록이 없는 기기는 1번부터 시작합니다.
- 제한 횟수 안에 별 타일만 모두 제거하면 성공합니다. 별 없는 숫자는 남아도 됩니다.
- 이웃한 숫자 3개 이상을 누른 채 연결합니다. 대각선, 꺾인 경로, 역순, 공차 0, 분수 공비도 허용합니다.
- 제거 후 위의 타일이 아래로 내려오며 새 타일은 생기지 않습니다. 잘못된 연결은 이동 횟수를 소모하지 않습니다.
- 초반 스테이지의 설명을 유지합니다. 플레이 방법에서 등차·등비 드래그와 낙하 애니메이션을 볼 수 있습니다. 시범을 멈출 수 있고, 동작 줄이기 설정에서는 정지된 설명을 제공합니다.
- 실패 시 같은 판을 재도전합니다. 플레이 중 다시하기는 설정 안에 있습니다. 되돌리기·아이템은 없습니다. 11단계부터 망고 힌트를 사용할 수 있습니다.
- 숫자 타일과 도움말 시범에는 구분하기 쉬운 Outfit 800 글꼴을 사용합니다. 플레이 방법은 메인화면에서만 열 수 있습니다.
- 키보드: Tab으로 숫자에 이동하고 Space로 선택한 후 선택 완료를 누릅니다. Escape는 선택을 취소합니다.
- 터치 시작은 타일 전체에서 받지만, 드래그 중에는 타일 중심의 원형 영역에 진입해야 연결됩니다. 대각선으로 지나가며 옆 칸 모서리를 스치는 입력은 무시하고, 빠른 드래그는 두 입력 사이의 경로도 검사해 중간 숫자를 놓치지 않습니다. 이전 타일 중심으로 돌아오면 선택을 한 칸 되돌립니다. 화면 크기가 바뀌거나 터치가 취소되면 이동 횟수를 쓰지 않고 선택을 취소합니다.

## 진행 저장

기기 내 localStorage만 사용하며 서버에 저장하거나 다른 기기로 동기화하지 않습니다. 현재 스테이지의 키만 저장하며 보드 상태·남은 횟수·연결 이력은 저장하지 않습니다. 메인에서 다시 시작하거나 새로고침 후 돌아오면 같은 스테이지의 원래 판과 전체 이동 횟수로 시작합니다. 기존 v1 저장 데이터는 스테이지 키만 이전하며 완료 기록은 유지합니다. 완료한 판은 다음 미완료 스테이지로 이어집니다. 저장소를 사용할 수 없어도 게임은 실행됩니다.

- `sequencepang2-active-v1`: 마지막 스테이지 키 (내용 형식 v2, 과거 연결 이력은 제거)
- `sequenstar-campaign-v2`: 기존 사용자 완료 기록과의 호환성을 위해 유지한 내부 키 (화면에는 이전 이름을 사용하지 않음)
- `sequencepang2-v1`: 초창기 기록 읽기 지원
- `sequencepang2-sound`: 효과음 설정. 이전 효과음 키도 읽습니다.

## 캠페인

1–30번의 숫자, 별, 제한 횟수, 고정 키를 유지합니다.

| 구간 | 구성 |
| --- | --- |
| 1–10 | 규칙 입문 8판, 두 번 연결하는 연습 2판 |
| 11–16 | 최소 3수, 순서와 낙하 |
| 17–24 | 최소 4수, 준비 수와 복합 연결 |
| 25–30 | 5×5, 최소 5수 |
| 31–50 | 5판씩 네 묶음: 4×4 3수 → 4×4 4수 → 5×5 4수 → 5×5 5수 → 구간 난제 |
| 51–100 | 다섯 장, 각 장마다 숨 고르기 → 선택 → 준비 수 → 낙하 → 고난도 5판을 두 번 반복 |

31·36·41·46번은 작은 판에서 여러 첫 수로 풀리고, 35·40·45·50번은 성공 가능한 첫 연결이 하나인 판입니다. 난이도 지표는 사람의 체감 순서를 완전히 보장하지 않으므로 플레이 반응에 따라 조정할 수 있습니다. 51–100번은 새 고정 퍼즐이며 다섯 장에 10판씩 배치됩니다. 공개 전에는 단계 수와 새 단계 예고를 게임 화면에 표시하지 않습니다.

`npm run generate:campaign`은 11–30번, `npm run generate:expansion`은 31–50번, `npm run generate:encore`는 51–100번을 고정 시드로 재생성합니다. 퍼즐은 플레이 중 생성하지 않습니다. 개발용 데이터에 정답 경로와 검증 지표를 보관합니다.

### 장기 캠페인 로드맵

현재 게임에는 1–100단계가 구현되어 있습니다. 101단계 이후는 스토어 게시와 장기 업데이트를 고려한 기획 단계이며, 서리·고정·연동·변환·미지수·양면 기믹과 후반 조합/마스터 퍼즐을 거쳐 500단계까지 확장하는 방향을 잡고 있습니다.

상세 설계와 구간별 원칙은 [`docs/campaign-roadmap-500.md`](docs/campaign-roadmap-500.md)를 참고하세요. 미래 기믹과 단계 배치는 프로토타입 및 모바일 플레이테스트 결과에 따라 축소·교체될 수 있습니다.

## 주요 파일

- `dist/app.js`, `index.html`, `style.css`: 화면, 드래그, 도움말과 애니메이션
- `dist/sequencepang2-logo-v2.jpg`: 사용자가 제공한 새 로고. 전달 파일은 알파 채널 없는 JPEG이므로 CSS screen 합성으로 검은 바탕을 배경에 통합하며 원본 픽셀은 변경하지 않습니다.
- `dist/engine.js`, `session.js`: 수열 규칙, 낙하, 게임 상태
- `dist/progress.js`: 완료 기록 이전, 스테이지 저장 및 처음부터 재시작
- `dist/levels.js`, `campaign-data.js`, `expansion-data.js`, `encore-data.js`, `release.js`: 100개 고정 퍼즐과 공개 시점
- `tests/`: 전체 퍼즐 해결 가능성, 최소 수, 저장·복원·실패·재시작 검증

전체 100판의 중도 종료 후 처음부터 재시작, 이전 저장 형식 이전, 잘못된 저장 데이터 처리와 완료 기록 유지도 검사합니다. 모바일 실기기의 터치 검사는 별도입니다.


## 홈 화면 설치 · 오프라인

- 메인 상단 **앱 설치**를 누르면 지원되는 브라우저의 설치 창 또는 기기별 설치 방법을 표시합니다. 설치한 앱에서는 설치 버튼을 숨깁니다.
- 이름은 시퀀스팡2, 실행 방식은 standalone입니다. 안드로이드용 192/512px 및 maskable 아이콘, iOS용 180px 아이콘과 파비콘을 제공합니다.
- 최초 온라인 접속 후 오프라인 저장이 끝나면 공개 시점에 따른 스테이지, 로고, UI, 한글·숫자 글꼴까지 인터넷 없이 사용할 수 있습니다. 설치 안내창에서 저장 완료 여부를 확인할 수 있습니다.
- 진행 기록은 기존과 동일한 기기·브라우저 저장소를 사용합니다. 웹앱 삭제 또는 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다.
- 새 서비스 워커는 플레이 중 강제 적용하지 않습니다. 다음 실행 때 적용하거나 메인의 **새 버전으로 업데이트**를 눌러 적용합니다. 진행 중이던 스테이지는 처음부터 시작합니다.
- 소스나 리소스를 바꾼 뒤 `npm run build:pwa`를 실행하여 `dist/sw.js`를 갱신합니다. Vercel 빌드도 자동 실행하며 CI는 오래된 오프라인 번들을 검사합니다.
- `dist/fonts/`는 Google Fonts의 Jua, Outfit(라틴 문자 부분)을 포함합니다. 각 OFL 라이선스를 함께 배포합니다.
- `dist/icons/`는 기존 로고를 참조해 내장 이미지 생성 도구로 제작한 망고·별·숫자 2 아이콘의 기기별 출력 파일입니다. 생성 프롬프트: 기존 로고의 귀여운 망고 캐릭터와 3D 질감을 유지하고 숫자 2가 새겨진 금색 별을 든 정사각형 앱 아이콘. 짙은 초록 배경, 작은 크기에서 읽히는 단순한 구성, 글자와 테두리 제외.

설치 기준 참고: [MDN PWA 설치](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable).

## 보안 응답 헤더

`vercel.json`은 모든 경로에 CSP, 프레임 삽입 차단, MIME 추측 방지, Referrer-Policy, Permissions-Policy를 설정합니다. 게임 스크립트·이미지·폰트·서비스 워커는 같은 출처만 허용하며 인라인 스크립트와 eval은 허용하지 않습니다. 카메라·마이크·위치·결제·USB 권한도 사용하지 않습니다.

게임판 크기와 낙하 위치는 JavaScript의 개별 style 속성으로 지정하므로 인라인 스타일 속성 허용 없이 동작합니다([MDN style-src-attr](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/style-src-attr)). 외부 리소스나 API를 추가할 때는 필요한 출처만 정책에 추가하고 다시 확인하세요.

`vercel.json`도 PWA 캐시 버전에 반영합니다. 헤더 변경 후에도 `npm run build:pwa`를 실행하며, 기존 설치 앱은 새 서비스 워커가 활성화된 뒤 갱신된 응답 헤더를 사용합니다. 기존 탭을 강제 종료하거나 진행 기록을 초기화하지 않습니다. Vercel에서 제공하는 HSTS와 기존 manifest·서비스 워커 캐시 정책은 유지합니다.

이 설정은 Vercel 배포 시 적용됩니다. 단순 개발 서버인 `npm start`는 Vercel 헤더 규칙을 자동 적용하지 않으므로 실제 헤더 검사는 해당 규칙을 적용한 검증 서버 또는 배포 응답에서 해야 합니다.


## 망고 힌트 (11단계부터)

- 설명 패널 대신 망고 버튼이 아래부터 ⅓씩 채워집니다. 실패 3회에 완전히 채워지고 이후 유지됩니다.
- 같은 스테이지에서 실패 3회면 시작 숫자, 5회면 첫 연결 경로가 열립니다. 이동 소진 또는 더 이상 연결할 수 없어 실패한 시도만 셉니다. 잘못된 연결, 설정의 다시하기, 중도 종료와 새로고침은 실패로 세지 않습니다.
- 열린 힌트는 해당 스테이지에서 계속 볼 수 있으며 자동 노출하지 않습니다. 시작 숫자는 반짝임과 빛나는 테두리로만 표시하고, 첫 연결은 터치 표시와 선이 경로를 따라가는 시범으로 보여줍니다. 좌표 설명과 순서 번호는 화면에 표시하지 않습니다. 직접 연결하면 시범이 사라지고 이동이 진행됩니다.
- 처음 배치 기준입니다. 진행 중 요청하면 확인창을 거쳐 같은 판을 처음부터 시작합니다. 취소하면 현재 판을 유지합니다. 타일을 선택하기 시작하면 힌트 표시를 지웁니다.
- `sequencepang2-hints-v1`에 스테이지 키와 배치 서명별 실패 횟수(최대 5)를 저장합니다. 재접속해도 유지하며 게임 초기화 시 삭제합니다. 저장소가 막혔을 때는 현재 접속 동안만 유지합니다.
- `node scripts/generate-hints.mjs`로 정답 탐색 후 첫 연결만 `dist/hint-data.js`에 생성합니다. 모바일에서 정답 탐색을 실행하지 않습니다. 배치가 바뀌어 서명이 맞지 않는 힌트는 노출하지 않습니다.
- 스테이지를 추가하거나 변경하면 힌트 생성 후 `npm run build:pwa`를 실행합니다. 테스트는 모든 힌트 이후 제한 수 안에 클리어 가능한지 검사하며, 데이터가 없는 새 스테이지는 테스트를 실패시킵니다.

시범은 게임 상태나 이동 횟수를 바꾸지 않으며, 창 닫기·화면 이동·백그라운드 전환 시 중단합니다. 동작 줄이기 설정에서는 시작점과 정지된 경로를 보여줍니다.

## 배경음악 · 효과음

설정에서 전체 음소거, 메인 배경음악, 효과음과 각각의 음량을 조절합니다.
메인에는 「망고 정원」이 반복되며 **플레이 화면에서는 BGM을 재생하지 않습니다**.
버튼을 누를 때의 공통 효과음은 없으며, 블록을 이어갈 때 올라가는 음계와
수열 완성·별 획득·망고 힌트·클리어·실패·전체 완료 효과음은 유지합니다.
화면 상단에 별도의 소리 버튼을 두지 않고 설정으로만 제어합니다.
